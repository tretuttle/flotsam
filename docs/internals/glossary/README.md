# Glossary

The words the code and the product use, one line each. Each change adds the terms it introduces to its own area file so parallel changes do not conflict.

- [Product and people](product.md) - Product name, supported browsers, user, and maintainer.
- [Processes and principals](principals.md) - Gecko process model, security principals, and experiment APIs.
- [Capture](capture.md) - DevTools capture and browser-level request and body capture.
- [Recording](recording.md) - Always-on background recording, storage layout, reconciliation, and retention.
- [Export](export.md) - HAR export, merging, redaction, and missing-body reporting.
- [Extension](extension.md) - Contract, engine, and extension-host wiring.
- [Harness](harness.md) - Real-browser test harness, fixtures, and measurements.
- [UI](ui.md) - Popup, history, and options pages.
- [Standard](standard.md) - Standard WebExtension build for browsers without experiment APIs.
